# GiziCare
Sistem Rekomendasi Makanan dan Minuman berdasarkan kebutuhan gizi biologi tubuh individu dengan menggunakan algoritma Machine Learning dari K-Nearest Neighbor

#Langkah Instalasi
1. Masuk ke folder Frontend dan backend.
2. Buka terminal atau pakai shortcut CTRL + J untuk membuka terminal dan ketik cd nama_folder.
3. ketik "npm install" untuk menginstall depedency dan juga node_modules.
4. jika sudah maka proyek siap dijalankan.
Note: Jangan lupa buat file .env untuk memanggil database, cross-origin, dan lainnya.
